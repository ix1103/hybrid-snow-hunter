# Hybrid Snow Hunter

AI-powered ski resort finder and condition analyzer.

## Getting Started

### Prerequisites

- Node.js 18+ installed

### Installation

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) with your browser.

## Features

- **AI Analysis**: Weather and condition scoring for ski resorts.
- **Interactive Map**: View resorts on a map with condition markers.
- **Detailed Forecast**: 7-day weather forecast and snow depth.
- **Comparison**: Compare up to 3 resorts side-by-side.
