# 開発ルール

## 確認・デプロイのフロー

1. コードを変更したら `npm run dev` で開発サーバーを起動する
2. ブラウザで `http://localhost:3000`（または 3001）を開いて動作確認する
3. ユーザーから「PUSH して」「GitHubにあげて」など明示的な指示があった場合のみ `git push` する

## Git 操作ルール

- `git add` と `git commit` はOK（ローカルのみ）
- **`git push` は ユーザーの明示的な指示があるまで絶対に実行しない**

## ローカルサーバー起動

```
npm run dev
```

ポート3000が使用中の場合は 3001 などに切り替わる。  
起動後にブラウザ確認を促すこと。
